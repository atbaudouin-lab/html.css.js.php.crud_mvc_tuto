# Fonts

Ce dossier contient les polices locales et la librairie d'icones du site.

## Contenu actuel

- `inter/` : police `Inter` locale au format `woff2`, chargee globalement depuis `css/style.css`.
- `font-awesome/` : `Font Awesome Free` auto-heberge avec sa feuille `css/all.min.css` et ses `webfonts/`.

## Pourquoi

Utiliser des polices locales peut ameliorer la performance, reduire la dependance aux sources externes et mieux maitriser le rendu du site, a condition de ne charger que les variantes utiles.
